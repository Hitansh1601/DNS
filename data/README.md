# Data directory

## Real dataset (NOT included)

Primary: **CIC-Bell-DNS-EXF-2021**
Official source: https://www.unb.ca/cic/datasets/dns-exf-2021.html
Download: http://cicresearch.ca/CICDataset/CICBellEXFDNS2021/ (registration form required)

Steps:
1. Open the official page, read feature docs, licence, and citation.
2. Complete the official download form.
3. Place downloaded CSVs in `data/` locally (do NOT commit them).
4. Record file names, shape, columns, label values, and run `python -m src.data_loader` to audit.

Licence (from official page): you may redistribute/republish/mirror with citation to the dataset and the paper below. Check the official page for current terms.

Citation:
> Samaneh Mahdavifar, Amgad Hanafy Salem, Princy Victor, Miguel Garzon, Amir H. Razavi, Natasha Hellberg, Arash Habibi Lashkari, "Lightweight Hybrid Detection of Data Exfiltration using DNS based on Machine Learning", The 11th IEEE International Conference on Communication and Network Security (ICCNS), Dec 3-5, 2021.

Documented stats (from official page, verify after download):
- 323,698 heavy attack, 53,978 light attack, 641,642 benign samples (structured rows).
- 30 features (14 stateless + 16 stateful). See official Table 1.

## Synthetic demo data (INCLUDED, clearly synthetic)

`data/synthetic_dns_demo.csv` is a **synthetic, clearly non-real** dataset generated by `src/synthetic.py` to let tests, CI, and the Streamlit demo run without the gated CIC download. Column names follow the documented feature names but values are randomly generated. NEVER present synthetic metrics as real CIC results.

Generate:
```
python -m src.synthetic --n 5000 --out data/synthetic_dns_demo.csv --seed 42
```
